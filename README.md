# 一生的气候 · D3 滚动动画

前端是纯 HTML/CSS/D3，三者分文件；没有 React，也没有伪造的气候数据。初始页面可操作出生年份、年龄条、滚动情景和五个地区；真实数值在载入 climate.json 后显示。

## 接入已有 NPZ

本段四情景比较只需要 `scenariomip_cesm2.npz`。`cesm2.npz` 的理想化 C4MIP 实验不属于另外两种减排情景；LS3MIP 的 land-hist 是陆地单独驱动实验，不直接拼成耦合模型历史温度。

在 NPZ 所在的 Colab/机器运行，不用重新下载 NPZ：

```sh
pip install numpy
python export_web_data.py
```

默认生成 `climate.json`，也可用 `--output` 指定位置。在网页文件选择框载入这个 JSON，或把它放到 同一个文件夹。压缩 NPZ 不能随机直接读取某个变量；导出器顺序跳过前面的变量，只保存温度层，因此仍需要一些解压时间。

预览：

```sh
python -m http.server 8000
```

访问 http://localhost:8000 。所有文件放在同一个文件夹，可直接放入原课程仓库；所有资源路径均为相对路径。

## 五个地区

坐标均为 [经度, 纬度]，仅用于定位。统计范围由 export_web_data.py 中明确的经纬度框定义，框内海陆均包含，不等同于国家行政边界。

| 故事 | 标记 | 改善方向 |
|---|---|---|
| 加州 | [-120, 38] | 减轻森林和居民承受的热压力；进一步用水分、火灾、碳库数据检验 |
| 印度 | [78, 23] | 减轻户外劳动和作物的热压力；不直接换算工时或产量 |
| 中国长江流域 | [111.5, 30.5] | 减轻复合干热中的温度压力；可另接径流和净碳吸收 |
| 亚马逊 | [-60, -4] | 减轻雨林水热压力；碳储存改善还受干旱、土地利用影响 |
| 东南亚沿海 | 越南 [105.78, 10.03]；菲律宾 [125, 11.25] | 展示当地升温改善；完整海平面预测可作为第二指标接入 |

## 数据口径

- 只用 `Amon__tas`，统一为相对 SSP585 2015–2034 温度场的变化（K 的差值等于 °C 的差值）。不是相对工业化前的升温。
- 年均按 noleap 月长加权；显示居中十年平均，端点使用可用窗口。
- 出生年份只转换年龄与日历年；年份范围 2015–2100；不把出生年份暗中用作各自基准。
- 地图做 4×4 面积加权聚合；全球和地区均值使用原网格球面格点面积权重。
- 原始时间序列遇到缺失值严格传播 NaN；空间汇总对有值格点归一化权重，无有效格点仍缺失。
- 各情景颜色范围和右图坐标保持一致。差距指标是十个区域框均值的最大值减最小值。低排放是否缩小差距，使用数据结果；没有预设排序。
- 相比高排放的差值地图包含负数，避免把局部未改善隐藏。
- 本段不能证明不同群体的经济损失、粮食产量或伤亡；也没有将 zos 解释成完整海平面上升。

五地区研究背景：IPCC AR6 https://www.ipcc.ch/report/ar6/syr/ ；CESM https://www.cesm.ucar.edu/ 。

将已有的 scenariomip_cesm2.npz 放在 export_web_data.py 旁边即可。cesm2.npz 和 ls3mip_cesm2.npz 也可以放在这里；本段温度四情景比较只读取 ScenarioMIP。压缩包不包含这三个大文件。


## 中国南方历史页面（新增）

所有文件仍放同一文件夹。把已有 `ls3mip_cesm2.npz` 放入该文件夹：

```sh
pip install numpy
python export_yangtze.py
python -m http.server 8000
```

打开 http://localhost:8000/yangtze.html 。原全球页面仍是 index.html。
也可用 `python export_yangtze.py --input /path/ls3mip_cesm2.npz`。

- 顺序解压一次 land-hist__data，按时间平面读取，只保留 100–122°E、24–35°N 区域。不会将整个大数组加载进内存。
- 输入为 (变量, 月份, 纬度, 经度) C顺序数组；自动检查维度和夏季月份完整性。
- 气温和表层土壤水按无闰日月长加权取夏季均值；GPP与可用的NBP积分为 g C/m²/夏季。任何月NaN均严格传播。
- 黑圈面积对应GPP，所有年份固定尺度；提示框显示1981–2010同一格点基准差值。无跨年平滑。
- NBP可用则写入JSON，不绘制；缺失时为null。不会用GPP冒充净吸收。
- 可选LAI≥3筛选采用固定基准，不是森林分类。区域框不是精确流域边界。
- land-hist是历史陆面模拟；新闻案例是另行引用的2022事实，两者不混为一谈。
- JSON不存在时显示生成方法，不内置虚构气候数据。

新增文件：yangtze.html / yangtze.js / yangtze.css / export_yangtze.py。


## 页面拆分（新版）

- index.html：出生年份、年龄条、四情景滚动动画、全球地图和宏观地区升温差距。无地区定位点或地方故事。
- regions.html：五个地区定位、独立日历年份、独立排放情景、当地改善说明与地区对比。没有出生年份或滚动驱动。
- yangtze.html：从地区页进入的中国南方历史专题，保留既有功能。
- 两个情景页面共享 climate.json；历史专题读取 yangtze.json。三个页面通过普通链接连接。
- JS唯一外部依赖是同目录d3.min.js；无React、Scrollama、GSAP、地图SDK或其他JS库。滚动处理使用D3事件与D3计时器。
